This project extends the original grid-based game by incorporating real-time weather effects from an HTTP server. The weather feed affects the game visually, dynamically updating each grid cell based on rainfall, wind, and temperature data. The system leverages design patterns, lambdas, and streams to ensure modularity, readability, and scalability. However due to errors in the code the only aspect of the weather that visually appears on the screen is the heat. The use of streams can be seen in the way the code processes and applys weather to the grid. This can be seen in lines such as weatherGrid.forEach((point, wd) -> {...}). This line iterateas over the existing cells, allowing the grid to be affected by weather. Lambdas are used to apply weather affects dynamically, based on attribute and intensity, as seen in the line wd.attributes.forEach((attr, val) -> {...}). Furthermore, thanks to the use of lambdas, we can reduce boilerplate iteration code, making the code more flexible since all you need to do to add more weather affects is simply go into weather effects and register something new.The weather server provides four attributes: rain, windX, windY, temp. Each is a floating-point number in [0.0, 1.0]. Rain is visualized as a blue overlay. Temperature is visualized as red/orange overlay. Wind is visualized as light gray overlay. Unfortunately though, the red/orange colour tends to overlay on top of everything, making it hard to see the indicators of wind and rain. There is also a feature within the code that causes the colors to dissappear after a certain period of time, allowing for a more dynamic looking game and making sure the weather doesn't cause the whole grid to turn red. Through this code, I have also portrayed decorator-like behaviour, creating a game that dynamically and uniquely modifies a cells appearence, by having the various weather effects uniquely change the way a cell looks without having to modify cell directly. Through this, I have displayed an effective use of lambdas and streams, displayed the use of design patterns which contribute to good game design and have effectively been able to utilise the provided values from the server to enhance my games design. In order to run this program, you need java 11 and simply have to run the main finction in java.
